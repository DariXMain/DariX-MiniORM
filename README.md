# 🗄️ DariX MiniORM

> **A lightweight MySQL ORM wrapper for rapid backend development**  
> *Developed by [DariXmain](https://github.com/DariXMain), a 16-year-old developer from Iran*

[![Python Version](https://img.shields.io/badge/python-3.7%2B-blue)](https://python.org)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)
[![MySQL](https://img.shields.io/badge/mysql-8.0%2B-orange)](https://mysql.com)

## ✨ Features

- 🔌 **Simple Connection Management** - Connect, disconnect, reconnect with ease
- 📝 **CRUD Operations** - Insert, Select, Update, Delete made simple
- 📊 **Auto Logging** - Built-in file logging system with timestamps
- 🔄 **Transaction Support** - Auto rollback on errors
- 💪 **Type Hints** - Full type hints for better IDE support
- 🚀 **Lightweight** - Just a wrapper around mysql-connector, no bloat
